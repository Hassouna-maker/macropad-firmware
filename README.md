# MacroPad firmware

- `macropad_s3/` – main board (ESP32-S3)
- `joystick_c6/` – wireless stick (ESP32-C6)

Every change is compiled by GitHub (Actions tab). The two update files are on the **Latest firmware** release:
https://github.com/Hassouna-maker/macropad-firmware/releases/tag/latest

In the pad's setup page, `macropad_s3.ino.bin` goes in the main board area and `joystick_c6.ino.bin` in the stick area.
