# Core Terrain

Terrain and biomes only, extracted from **Core Craft v1.2.9**: the `ct:snowy_dappled_forest` biome,
per-biome ground/surface rules, End cliff terrain, ice caves/geodes/icicles, boulders, oases, mud
patches and End stone spikes. No custom trees (apart from oasis palms), plants, logs, ores, villages or
other structures.

- Namespace `cc:` -> `ct:` (don't enable alongside Core Craft in the same world).
- No scripts. Core Craft's script-driven block behaviours (coconut growth, etc.) are removed.
- Only newly generated chunks are affected: use a new world.
- Source: Core Craft by its original author (CurseForge). Check its license before redistributing.
