# Core Terrain

Terrain and biomes only, extracted from **Core Craft v1.2.9**: the `ct:snowy_dappled_forest` biome,
the per-biome ground/surface rules (meadow, savanna mud, stone shores, lavender, snowy, jungle roots,
End biomes), End cliff terrain elevation, ice caves/geodes/icicles, boulders, oases, mud patches and
End stone spikes. No custom trees, plants, logs, mushrooms, ores, villages or other structures.

- Namespace `cc:` -> `ct:` (don't enable alongside Core Craft in the same world).
- No scripts. Only newly generated chunks are affected: use a new world.
- Source: Core Craft by its original author (CurseForge). Check its license before redistributing.
