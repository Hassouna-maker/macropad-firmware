# Core Terrain

Standalone Bedrock addon holding the world generation extracted from **Core Craft v1.2.9**:
the `ct:snowy_dappled_forest` biome, all feature rules (custom trees, vegetation, boulders, logs,
ores, End terrain/cliffs, mud/swamp/desert/jungle ground cover, vanilla tree resets), the
structure templates those features place, and the custom blocks and textures they need.
Villages, ruins, temples, mineshafts and other structures are not included.

- Namespace renamed `cc:` -> `ct:` so it can be installed next to Core Craft (don't enable both in one world).
- New pack UUIDs. No scripts required.
- Only affects newly generated chunks: use a new world.
- Source: Core Craft by its original author (CurseForge). Check its license/permission before redistributing.
