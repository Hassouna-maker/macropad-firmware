# Core Terrain

Standalone Bedrock addon holding the world generation extracted from **Core Craft v1.2.9**
(biome `ct:snowy_dappled_forest`, per-biome surface/vegetation feature rules, the End cliff
terrain elevation, and the custom blocks those features place).

- Namespace renamed `cc:` -> `ct:` so it can be installed next to Core Craft.
- New pack UUIDs. No scripts required.
- Source: Core Craft by its original author (CurseForge). Check its license/permission before redistributing.
